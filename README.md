# داش بورد البيانات — تطبيق PWA على GitHub Pages

## الملفات
- index.html — الداش بورد (البيانات مدمجة داخل الملف)
- manifest.json — بيانات التطبيق (الاسم، الألوان، الأيقونات)
- sw.js — عامل الخدمة للعمل بدون إنترنت بعد أول فتح
- icons/ — أيقونات التطبيق

## خطوات النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، مثلاً: dashboard
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع (الملفات نفسها وليس المجلد)
3. من Settings > Pages اختر:
   - Source: Deploy from a branch
   - Branch: main / (root)
4. بعد دقيقة تصبح الرابط: https://USERNAME.github.io/dashboard/

## التثبيت على الموبايل
- Android (Chrome): افتح الرابط، ثم القائمة ⋮ > "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
- iPhone (Safari): افتح الرابط، ثم زر المشاركة > "إضافة إلى الشاشة الرئيسية".
- الكمبيوتر (Chrome/Edge): أيقونة التثبيت في شريط العنوان.

## ملاحظات
- التطبيق يتطلب HTTPS، وGitHub Pages يوفره تلقائياً.
- عند تحديث البيانات أو الملف، غيّر رقم الإصدار في sw.js من dashboard-v1 إلى dashboard-v2 حتى يحمّل المستخدمون النسخة الجديدة.
- الخطوط تُحمَّل من Google Fonts عند الاتصال الأول وتُخزَّن بعدها.
